# Third-party notices

This starter repository contains no game assets and no source copied from the referenced game ports. It links to them as design/build references only.

Before integrating source code, libraries, generated code, shader code, fonts, or assets from any upstream repository, review and record the applicable licenses and notices. Do not assume that the license of an Android launcher automatically covers the game code, PS2Recomp, SDL3, shaders, or other dependencies.
